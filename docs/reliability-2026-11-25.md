# Проверка и изменения ZSKI

## Исходное состояние

Работа начата с GitHub main b6abece56766eacdde3279535ed6c593e95f0ee7. Штатная сборка и синтаксис JavaScript прошли до изменений. AGENTS.md в репозитории отсутствует. Задание получено в приложении. Отдельное сообщение пользователя разрешает обновление GitHub. Публикация на SpaceWeb ожидает согласования.

На http://zski.ru.swtest.ru/ находится сборка 202611231712. На GitHub Pages была сборка 202611221315. Их код различался. Данные js/data.js совпали после нормализации переводов строк.

Сохранены две ветки.

- backup/before-reliability-2026-11-25 сохраняет весь исходный репозиторий.
- backup/spaceweb-before-reliability-2026-11-25 содержит снимок опубликованных HTML, CSS и JavaScript поверх исходного репозитория. Медиа в этой ветке взяты из исходного GitHub. Закрытые серверные настройки и файловая система хостинга не выгружались.

## Изменения и зависимости

Галерея перенесена в js/gallery.js, форма в js/contact.js, погода в js/weather.js, сообщения о сети в js/connectivity.js. В main.js исключение независимого блока больше не останавливает следующие блоки. Клавиатурные вкладки и меню из SpaceWeb сохранены.

Калькулятор использует прежний прайс и формулу. Кнопки называют конкретную позицию, итог доступен скринридеру. Квиз сохраняет прежний подбор и предлагает копирование текста. WhatsApp получает текст через свой параметр, Telegram и MAX открываются отдельно. На реальных устройствах адресат и поведение мессенджеров требуют проверки.

При крупном тексте нижняя панель действий переносит кнопки в два ряда. Нижний отступ страницы учитывает фактическую высоту панели, чтобы она не закрывала конец содержимого.

Текст квиза про «мягкие настройки креплений» сохранён согласно ограничению задания. Для согласования с мастером предложена формулировка «Окончательный комплект и настройки креплений подберёт мастер с учётом ваших параметров и опыта».

Главная больше не встраивает скрытую сцену и её стили. Кнопка ведёт на существующую intro.html, включая сценарий без JavaScript. Художественная сцена сохранена. Из SpaceWeb перенесены изменения загрузки, повторного запуска и выбора видеоверсии.

Версия картинок и видео в HTML меняется при сборке. API, POST и Range-запросы не кешируются. Воркер активируется после закрытия старых вкладок. Сохраняется один предыдущий кеш ZSKI. Чужие кеши не удаляются.

Серверная часть находится в api/contact.php и lib/contact.php. Добавлена PHPMailer 7.2.0, upstream commit f5eb50148734d03bbbb81825c722c1889636d51a. В lib/phpmailer включены три необходимых исходных файла, лицензия и версия. Проверка TLS не отключается. Фреймворки и сборщики не добавлялись.

Обработчик проверяет POST, формат, размер, типы, Unicode, длину, тему, телефон, пустые значения, дополнительные поля и происхождение. Получатель и From задаются сервером. Пользовательские поля входят только в текст письма. Есть honeypot и SMTP-таймауты.

Параллельные запросы резервируют идентификатор под файловой блокировкой. Повтор не вызывает второе письмо. После неоднозначной ошибки SMTP идентификатор остаётся использованным. Интерфейс сообщает об отсутствии подтверждения.

Ограничение составляет три попытки с одного адреса за десять минут и тридцать попыток всего за десять минут. Имя, телефон, текст и открытый IP в техническом состоянии не записываются. Сохраняются HMAC и случайный номер обращения. Техническое состояние имеет срок жизни один час, очистка выполняется при запросах. Эти интервалы не задают срок хранения писем в ящике.

Ответы имеют no-store/private. JSON не содержит полей обращения. Без JavaScript ошибка возвращает HTML с экранированными введёнными данными. Успешный POST перенаправляет 303 на подтверждение со случайным номером, без контактов в URL.

Основные затронутые файлы перечислены в Git diff. Это шаблоны index/contacts/intro, общий head/footer, CSS, часы и скрипты интерфейса, sw.js, build.py, stage.py, PHP и закреплённая библиотека, тесты, workflows и документация. Сгенерированные страницы сохранены вместе с исходниками.

## Что реально проверено

- Штатная сборка, синтаксис JavaScript и PHP.
- PHP 8.4.28 с подставным транспортом. Приём, повтор, подмена тела, неверные типы, Unicode, длина, попытки внедрения заголовков, подмена получателя, honeypot, Origin, rate limit, очистка и два параллельных процесса.
- Настройки PHPMailer для SMTPS/465 и STARTTLS/587, отказ от неизвестного или незашифрованного транспорта. Сетевое SMTP-соединение этим тестом не устанавливается.
- HTTP 404, 405, 413, 415, 403, 422 и 503. Отсутствие конфигурации. Сохранение полей в HTML ошибки.
- Chromium 156. Галерея с клавиатуры, Tab, Escape, фокус и прокрутка. Диалог видео маршрута и возврат фокуса.
- Калькулятор, все позиции, предел количества, комплект и шлем на два дня за 5 000 ₽.
- Все 18 сочетаний квиза, перезапуск и текст копирования.
- Форма с подставными ответами 200, 422, 429 и 502. Двойное нажатие, разрыв сети, сохранение введённого и отсутствие преждевременного успеха.
- Шесть основных страниц на ширинах 320, 375, 390, 768, 900, 1024 и 1440 CSS px. Проверено горизонтальное переполнение. Альбомный экран 740×360 и удвоенный базовый размер текста.
- Отказ data.js. Меню, статический прайс, галерея и форма доступны.
- Повреждённый кеш погоды и запрет localStorage. Свежий прогноз отображается.
- Реальное обновление сервис-воркера в Chromium. Старая вкладка, новая версия, переход, перезагрузка, закрытие старых вкладок, офлайн и восстановление сети. Кешированный HTML предупреждает об актуальности, POST не обслуживается из кеша.
- Ночной график по московскому времени, переход недели и границы сезона в Node-тестах.

## Что остаётся открытым

Реальные письма не отправлялись. Подставной транспорт подтверждает локальную логику. Получение в ящике не проверено. Реальные Android/iPhone, Safari, полный браузерный zoom 200%, внешние приложения и восприятие скринридером требуют приёмки на устройствах. Баллы Lighthouse и Core Web Vitals не измерялись.

Офлайн доступен только для ранее сохранённых страниц и ресурсов. Первое открытие сайта без сети не поддерживается.

GitHub Pages даёт статический просмотр, PHP на нём не исполняется. После замечания пользователя уведомление об этом показывается до заполнения, кнопка отправки отключена. В форме явно указаны получатель ZSKI и z_ski@mail.ru. Локальные проверки не означают настройку SMTP на SpaceWeb.

SpaceWeb описывает отправку через SMTP и PHP в документации. Фактические PHP/OpenSSL, исходящий доступ к SMTP, права закрытой папки и лимиты выполнения именно для ZSKI требуют проверки на целевом сайте. [Инструкция SpaceWeb](https://help.sweb.ru/nastrojka-smtp-na-sajte_973.html)

Перед включением формы нужно установить закрытую конфигурацию, уточнить реальный почтовый транспорт и выполнить разрешённую тестовую отправку. Также нужно утвердить сведения о фактической обработке обращений, тексты уведомления/согласия, сроки хранения писем, сведения о почтовом провайдере, журналы хостинга и соответствующие документы владельца. Эти сведения не выдумывались.

Старый основной zski.ru может содержать другой сайт. DNS, домен, SSL и почтовые записи в этой работе не менялись. SpaceWeb остаётся отдельной опубликованной версией до согласования переноса.
