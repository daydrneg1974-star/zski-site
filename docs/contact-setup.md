# Настройка серверной формы ZSKI

Нужен PHP 8.2 или новее с OpenSSL, доступ к SMTP с TLS и закрытый каталог для конфигурации и состояния. Composer на хостинге не требуется. PHPMailer 7.2.0 включена в репозиторий.

1. Скопировать config/contact.example.php в zski-private/contact.php рядом с public_html, за пределами веб-корня.
2. Заполнить SMTP host, port, encryption, username, password, From и To через файловый менеджер хостинга или SSH. Пароль в чат и Git не передавать.
3. Создать секрет командой php -r 'echo bin2hex(random_bytes(32)), PHP_EOL;' и сохранить в закрытом файле.
4. В origins перечислить точные разрешённые адреса со схемой и портом при необходимости.
5. Убедиться, что state_dir находится за веб-корнем и доступен PHP на запись. Обработчик создаёт его с правами 0700. Конфигурацию защитить правами 0600.
6. При другом расположении задать абсолютный путь переменной окружения ZSKI_CONTACT_CONFIG.
7. После разрешения на реальную отправку проверить результат в ящике проката. Принятие SMTP и получение письма фиксировать отдельно.

Для SMTPS используется smtps, обычно порт 465. Для STARTTLS используется tls, обычно порт 587. Host и порт берутся из настроек выбранного почтового ящика. Параметры конкретного ящика ZSKI ещё не установлены. Проверку TLS не отключать.

GET api/contact.php?status=1 с настроенным сервером возвращает доступность обработчика. Он не устанавливает SMTP-соединение и не подтверждает доставку. Без конфигурации обработчик возвращает 503.

Каталог публикации создаёт команда python3 tools/stage.py /absolute/path/zski-public. В него входят HTML, CSS, шрифты, картинки, JavaScript, видео, sw.js, robots.txt, sitemap.xml, api и lib. Файлы .htaccess ограничивают прямой доступ к библиотеке.

В веб-корень не должны попадать config, tests, docs, .git, локальные отчёты, архивы и zski-private. Обработчик отказывается использовать конфигурацию и состояние внутри веб-корня. Не копировать весь репозиторий в public_html.

Для GitHub Pages к команде добавляется --preview-url https://daydrneg1974-star.github.io/zski-site. В просмотре установлен noindex, robots.txt запрещает обход, PHP не публикуется. У формы до заполнения показано пояснение, кнопка отправки отключена и POST не выполняется. Основные canonical в исходниках сохраняются для будущей основной публикации. Перед SpaceWeb выбрать целевой статус размещения и сформировать соответствующую сборку. Получатель SMTP в закрытой конфигурации должен совпадать с показанным на форме адресом z_ski@mail.ru.

Откат выполняется публикацией проверенного предыдущего каталога. Закрытые секреты и состояние не переносить в веб-корень. Исходный репозиторий сохранён в backup/before-reliability-2026-11-25. Публичные текстовые файлы SpaceWeb находятся в backup/spaceweb-before-reliability-2026-11-25.

Для временного PHP-хостинга используется `--server-preview-url http://zski.ru.swtest.ru`. Этот режим включает обработчик и библиотеку, но сохраняет noindex, запрет обхода и отключённую форму с пояснением до полей. Пустая карта сайта заменяет старую при обновлении поверх файлов. Закрытая SMTP-конфигурация в пакет не входит. До настройки почты и защищённого адреса форму не включать.

Перед переносом 25 ноября 2026 в файловом менеджере SpaceWeb создана полная копия текущего `/zski/public_html` в `/zski/backup-before-contact-fixes-20261125`, за пределами веб-корня. PHP сайта — 8.4. Доступ к `z_ski@mail.ru` есть только у владельца проката: настройка SMTP и проверка получения письма остаются отдельным шагом с его участием. Реальные письма не отправлялись.
