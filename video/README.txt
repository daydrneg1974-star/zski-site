Ролик интро: descent.mp4 (H.264, для Safari) и descent.webm (VP9), 1280x720, 30 кадров/с, 18 с, без звука;
descent-540.* — лёгкие версии 960x540 для медленной сети (выбирает скрипт на главной по navigator.connection).
Все файлы собирает tools/retime_intro.py из исходника (плавные остановки смонтированы в ролике).
Не заменяйте файлы вручную: моменты станций в js/intro.js (блок TIMELINE) должны совпадать с роликом.
