# ZSKI — новый сайт проката лыж и сноубордов

Редизайн сайта [zski.ru](http://zski.ru) — прокат горных лыж и сноубордов, SKI-сервис,
хранение и консервация инвентаря в Яхроме, рядом с СНТ Каменка.

Анализ оригинального сайта (сильные и слабые стороны) — в [ANALYSIS.md](ANALYSIS.md).

## Дизайн

Светлая нейтральная тема в фирменных цветах Z·SKI (красный акцент, синий, графитовый текст
на светло-сером фоне; первый экран — фото с тёмной подложкой): дисплейный шрифт Unbounded для
заголовков и Manrope для текста, полноэкранный первый экран с медленным наездом камеры и лёгким
снегом, бегущая строка, сразу видимые блоки и показатели, лайтбокс для фотоальбома,
карточки с подсветкой при наведении. Все анимации отключаются при настройке системы
«уменьшить движение».

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: первый экран, преимущества, цены (вкладки), как это работает, сервис, склоны, видео, отзывы, FAQ, контакты с картой |
| `prices.html` | Полный прайс проката, калькулятор стоимости по количеству инвентаря и числу дней, распродажа |
| `service.html` | SKI-сервис: описание, прайс по разделам, когда пора в сервис |
| `slopes.html` | Склоны рядом: Спортивный парк Яхрома, Волен, Степаново, видеообзоры |
| `contacts.html` | Контакты, статус «открыто сейчас», график, карта, как добраться, видеомаршрут из Яхромы, серверная форма обратной связи |
| `clients.html` | Информация для клиентов с подзаголовком «Уголок потребителя»: ссылки на цены, услуги и контакты; открывается без интро |

Страница «Информация для клиентов» доступна из подвала основных страниц и из блока
контактов. Реквизиты ИП Рябининой Натальи Владимировны добавлены по предоставленной
выписке ЕГРН от 09.11.2026; источник для страниц и поисковой разметки — `owner` в `js/data.js`.
Дата государственной регистрации 09.11.2026 и регистрирующий орган — Межрайонная
инспекция Федеральной налоговой службы № 23 по Московской области — подтверждены
выпиской ЕГРИП от 22.11.2026, полученной с сервиса ФНС 23.11.2026. Инспекция № 8
отдельно указана как орган налогового учёта. Оригинал выписки сохранён локально в
`outputs/registry/2026-11-23/`, в публикацию и коммит не включается.
Почтового адреса ИП в этой выписке нет; Рифкат уточнит его позже.
Залог — водительское удостоверение либо 15 000 ₽ за комплект (согласовано 23.11.2026).
Источник денежной суммы — `rentalCashDeposit` в `js/data.js`.
Остальные условия договора пока предоставлены не полностью. Текущие цены, график и
контакты подтверждены Рифкатом 22.11.2026; старый сайт для их сверки не использовать.
Текущий статус подготовки к публикации —
в локальном файле [docs/RELEASE-STATUS.md](docs/RELEASE-STATUS.md).

## Скорость

- Шрифты лежат в `fonts/` (без запросов к Google Fonts); для них описаны метрически
  подогнанные системные запасные шрифты (`Unbounded Fallback`, `Manrope Fallback`),
  поэтому текст не «прыгает», когда догружается фирменный шрифт. Латинский
  расширенный набор урезан до знака ₽ (3 КБ вместо 118 КБ).
- Прайс, таблица SKI-сервиса, рейтинг и число оценок предрендерены в HTML при сборке
  из `js/data.js` (`src/build.py`, нужен `node`). Они видны и без JavaScript.
- Фотографии локальные, с WebP-версией. Первый экран имеет приоритет загрузки,
  снимки ниже подгружаются заранее при прокрутке. У изображений заданы размеры,
  чтобы место под них было готово до загрузки. Фотоальбом использует уже загруженный WebP.
- Тексты, цены, кнопки и итоговые значения показываются сразу, без задержанного проявления
  и анимации счёта от нуля. Снег останавливается, когда первый экран не виден.
- Внешний запрос погоды (Open-Meteo) не блокирует страницу. Три информационных ролика
  воспроизводятся обычным плеером браузера из `video/clips/`, без запросов к RUTUBE.
  Начало ролика готовится при приближении к видео; при экономии трафика — только по нажатию.
- Интерактивная карта Яндекса загружается по кнопке; до этого доступна ссылка на точку проката.
- Сервис-воркер `sw.js` кэширует статику и посещённые страницы для повторного открытия,
  в том числе без сети. HTML сначала запрашивается из сети. Браузеры с поддержкой
  Speculation Rules могут заранее готовить переходы по ссылкам.
- Погода кэшируется на час; даты обратного отсчёта до сезона задаются в `js/data.js`
  (`seasonStart`, `seasonEnd`).
- Ориентиры на эмуляции 4G (4 Мбит/с, 100 мс): первая отрисовка ≈0,5 с,
  LCP ≤1 с, сдвиг макета (CLS) ≤0,01 на всех страницах.

## Интро «спуск к прокату»

Главная открывается сразу. Кнопка «Спуск к прокату» ведёт на intro.html.
На отдельной странице кнопка «Поехали» запускает видео спуска от первого лица с пятью остановками: лыжник плавно тормозит, кадр замирает на 2 с,
появляется карточка раздела (Прокат → Цены → SKI-сервис → Склоны → Контакты); между остановками
~2,4 с хода. Наведение и фокус с клавиатуры удерживают паузу. На телефоне касание карточки удерживает
её до нажатия «Перейти», «Дальше» или касания за карточкой. Флажки на шкале под видео ведут к нужной остановке.
После последней станции ~6 с финального спуска. По окончании ролика зимнее фото павильона
и меню сайта появляются одновременно, без отдельной паузы и проявления меню.

**Плавность.** Движение и торможения смонтированы в ролике. Браузер проигрывает его
на скорости 1 и ставит паузу на станциях. Моменты станций и профиль скорости для спидометра,
ветра и шороха кантов заданы в блоке `TIMELINE` в `js/intro.js`. При замене видео сверьте с ним обе ориентации.

Длительность остановки — `CFG.hold` в `js/intro.js` (перемонтаж не нужен).

**Медленная сеть.** Плеер подбирает ориентацию и формат видео. После длительной остановки
показывает понятную ошибку и кнопку повторного запуска. Обычная ссылка на сайт доступна всегда.

**Если браузер не даёт запустить видео** без касания (энергосбережение на iPhone, запрет
автовоспроизведения), спуск не зависает: появляется подсказка «Коснитесь экрана, чтобы продолжить спуск».

**Основной вход.** Главная, цены, контакты и якоря доступны без просмотра сцены.
Возврат из разделов не запускает интро автоматически. На отдельной странице сохраняются
пропуск, остановки, видеомаршрут и управление звуком.

- Ролик показывает спуск от первого лица с экипировкой в цветах авторского изображения. Горизонтальная версия
  (1280×720) лежит в `video/`, вертикальная (720×1280) — в `video/portrait/`. В каждой папке
  есть MP4, WebM и лёгкие версии `descent-540.*`. Все файлы длятся 18 с при 30 кадрах/с.
  Ориентация экрана определяет видео и обложку при входе. Вариант «вид вслед за лыжником»
  (Pexels) — ветка `intro-video-v1`. Экспериментальная 3D-версия — `intro-3d.html` (three.js).
- Без JavaScript или при настройке «уменьшить движение» интро не показывается.

## Как редактировать

Все цены, контакты, график и ссылки на карты лежат в одном файле — **`js/data.js`**.
Поменяйте число там, и оно обновится на всех страницах и в калькуляторе.

- `phone`, `email`, `address` — контакты.
- `owner` — ФИО ИП, ИНН, ОГРНИП, дата и орган госрегистрации, сведения о налоговом учёте. Сборка выводит их
  в «Информации для клиентов», контактах, подвале всех основных страниц и Schema.org.
- Кнопки для водителей ведут к концу автомобильного подъезда: `56.270071, 37.48997`
  (`zskiDriveLat` / `zskiDriveLng`). Точка павильона в карте и Schema.org — `56.269875, 37.490032`,
  примерно в 22 м от подъезда. Различие намеренное: первая точка лежит на дороге
  [OpenStreetMap 1288098917](https://www.openstreetmap.org/way/1288098917), узел `11945488419`;
  геометрия сверена 21.11.2026. Сам съезд с 46Н‑01057 — `56.270594, 37.489554`.
  На телефоне `js/drive-links.js` открывает приложения; без них доступны веб-маршрут
  и координаты. В интро, на главной и в контактах рядом с навигаторами есть карточка
  «Как доехать из Яхромы»: она открывает ролик поверх текущего экрана.
  Кнопка «Скачать ролик · 8,3 МБ» сохраняет облегчённый MP4 для просмотра без интернета.
  В контактах есть полный плеер, фото развилки и панорама поворота.
- `whatsapp` / `telegram` — номер WhatsApp без плюса и имя пользователя Telegram без `@`.
  Если поля пусты, используется номер из `phoneHref`. Кнопки доступны
  на первом экране, в результате квиза, в нижних контактах главной и на странице контактов.
  Ссылки на чат формируются при сборке и работают без JavaScript. Наличие аккаунта и
  доступность поиска по номеру зависят от настроек владельца в мессенджере.
- Квиз подставляет выбранный инвентарь и расчёт в сообщение для уточнения наличия.
  Кнопка MAX передаёт его на экран выбора чата; для поиска указан номер `phone`.
- Калькулятор показывает стоимость выбранного инвентаря по количеству и числу дней.
- `hours` — график по Москве. `close: 26` означает «до 02:00 следующего дня». Статус в шапке и в интро обновляется без перезагрузки.
- `rental` — прайс проката, `service` — прайс сервиса.
- `rating` — рейтинг и число оценок на Яндекс Картах.
- Форма в контактах отправляет сообщение в PHP/SMTP-обработчик. На статическом просмотре GitHub Pages серверная отправка недоступна. Прямые почтовая и телефонная ссылки доступны отдельно.

Стили — `css/style.css`, логика — `js/main.js`. Тексты страниц — в `src/pages/`
(см. «Сборка» ниже). Собранный сайт — статические файлы в корне: открыть `index.html`
в браузере достаточно, серверу ничего не нужно.

## Сборка

HTML в корне генерируется скриптом **`src/build.py`** (нужны `python3` и `node`):

```
python3 src/build.py          # пересобрать index/prices/service/slopes/contacts/clients/intro.html и sw.js
python3 src/build.py --check  # убедиться, что HTML в корне соответствует исходникам
```

Исходники:

| Путь | Что там |
|---|---|
| `src/layout/head.html` | общий `<head>`: мета-теги, шрифты, стили (`{{TITLE}}`, `{{DESCRIPTION}}`, `{{CANONICAL}}`) |
| `src/layout/header.html` | меню и шапка |
| `src/layout/footer.html` | подвал, нижняя панель, подключение скриптов и сервис-воркера |
| `src/layout/schema.html` | разметка schema.org (организация, адрес, график) — на главной и в контактах |
| `src/pages/*.html` | содержимое `<main>` каждой страницы; в начале файла — `title`, `description`, `canonical`, по желанию `schema: yes` и `preload: <картинка первого экрана>` |
| `src/pages/intro.html` | интро целиком (своя разметка), копируется как есть |
| `src/render.mjs` | предрендер прайса и таблицы сервиса из `js/data.js` (разметка та же, что в `main.js`) |

Сборка подставляет штамп `?v=ГГГГММДДЧЧММ` ко всем css/js/шрифтам и в `VERSION` сервис-воркера.
После каждой правки пересоберите сайт и закоммитьте **и исходники, и HTML в корне**.
GitHub Pages публикует готовые страницы и ресурсы. Пустые `<ul data-pricelist="…">` и
`<div data-service>` в исходниках заполняются при сборке; правьте цены только в `js/data.js`.
Workflow `.github/workflows/check.yml` проверяет соответствие HTML исходникам при каждом пуше и в pull request. Workflow публикации повторяет проверку перед выкладкой.

  (свободная лицензия). Если фото недоступно, показывается фирменный градиент.
- Три информационных ролика лежат в `video/clips/`: подготовка лыж, Волен/Степаново,
  парк Яхрома. MP4 (H.264 + AAC), 30 кадров/с, ключевой кадр каждые 2 секунды,
  метаданные в начале файла (`faststart`): не нужно скачивать ролик целиком до запуска.
  Для компьютера — 720p, для телефона, медленной сети и экономии трафика — облегчённые 480p.
  Автозапуска нет; при начале одного ролика остальные останавливаются.
  Плеер работает и без JavaScript (тогда используется основной MP4).
  Источники и параметры сжатия записаны в `video/README.txt`. Видео интро лежит в `video/`.
- В контактах, в разделе «Видео и ориентиры», размещён отдельный видеомаршрут из Яхромы
  `video/clips/route-yakhroma.mp4` с облегчённой мобильной версией `route-yakhroma-480.mp4`.
  Длительность — 1 мин 38 с. Подписи проверены по исходникам: здание LADA обозначено
  как автоцентр «Яхрома-Лада», неподтверждённое «Выезд из Яхромы» заменено нейтральным
  «Далее по маршруту». Видео смонтировано из двух записей заказчика, с зимней обработкой
  и восстановленным финальным кадром. Три баннера показывают оставшееся расстояние:
  ≈ 1,8 км, ≈ 0,7 км и ≈ 0,1 км. Карточку и окно просмотра оформляет `css/route-video.css`,
  плеер открывает `js/route-video.js`; ссылки работают и без JavaScript, ведя к полному
  плееру в контактах. Скачивание — обычная ссылка с атрибутом `download` на мобильную
  версию MP4; сохранённый файл можно открыть без сети. Работа кнопки сохранения зависит
  от браузера: некоторые мобильные браузеры предлагают сохранение через своё меню.
- Карта — виджет Яндекс Карт по координатам павильона (`address.lat/lng`, `mapEmbed` в `js/data.js`).
- Скриншоты оригинального сайта для сравнения — в `docs/original/`.

## Публикация

**GitHub Pages:** в настройках репозитория Settings → Pages → Source выберите
«GitHub Actions». Workflow `.github/workflows/pages.yml` публикует сайт при каждом пуше
в `main`. Подключение `zski.ru` выполняется отдельно, после одобрения Рифката:
домен задаётся в Settings → Pages → Custom domain, затем настраиваются DNS и HTTPS.
При публикации через собственный workflow файл `CNAME` не нужен и игнорируется
([документация GitHub](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/troubleshooting-custom-domains-and-github-pages)).
Текущие настройки домена этой подготовкой не меняются.

`canonical`, Open Graph и Schema.org подготовлены для будущего адреса `https://zski.ru/`.
В `src/layout/schema.html` фотография указана как `https://zski.ru/img/photos/shop-exterior.jpg`.
До переноса сайта этот адрес возвращал HTTP 404 (проверка 21.11.2026). После выкладки
на домен нужно подтвердить HTTP 200 для него и для `og:image`. Публикация на GitHub Pages
обновляет демонстрационную версию и сама по себе не переносит сайт на `zski.ru`.

**Любой хостинг:** просто загрузите содержимое папки на сервер — это статические файлы.

## Проверка

Сайт проверен в headless Chromium на ширине 390 px и 1366 px: без ошибок JavaScript,
без горизонтальной прокрутки, калькулятор, вкладки, меню и статус работы функционируют.

## Проверка надёжности от 25 ноября 2026

Страницы редактируются в src/pages и src/layout. После правок запускать python3 src/build.py и сохранять сгенерированные HTML и sw.js вместе с исходниками. Контакты, цены и расписание задаются в js/data.js.

Главная открывается сразу. Видеоинтро доступно по ссылке на intro.html. Галерея, обратная связь, погода и отметки сети находятся в отдельных скриптах. Исключение одного блока main.js не блокирует остальные.

Воркер ждёт штатной активации после закрытия старых вкладок. Видео, Range, API и POST не кешируются. Офлайн-страница предупреждает об актуальности цен. Очереди отправки обращений нет.

Команды проверки приведены ниже.

    python3 src/build.py --check
    node --test tests/hours.mjs
    php tests/contact.php
    python3 tests/endpoint.py
    python3 tests/browser.py
    python3 tests/service-worker.py

Последним двум проверкам нужны Python Playwright и Chromium. Путь к браузеру можно передать через ZSKI_BROWSER, к PHP через ZSKI_PHP. Результаты и ограничения описаны в [отчёте](docs/reliability-2026-11-25.md), SMTP и состав публикации в [инструкции формы](docs/contact-setup.md). GitHub Pages служит статическим просмотром. Реальная отправка требует настройки SpaceWeb.
