# ZSKI — новый сайт проката лыж и сноубордов

Редизайн сайта [zski.ru](http://zski.ru) — прокат горных лыж и сноубордов, SKI-сервис,
хранение и консервация инвентаря в Яхроме (61-й км Дмитровского шоссе).

Анализ оригинального сайта (сильные и слабые стороны) — в [ANALYSIS.md](ANALYSIS.md).

## Дизайн

Светлая нейтральная тема в фирменных цветах Z·SKI (красный акцент, синий, графитовый текст
на светло-сером фоне; первый экран — фото с тёмной подложкой): дисплейный шрифт Unbounded для
заголовков и Manrope для текста, полноэкранный первый экран с медленным наездом камеры и лёгким
снегом, бегущая строка, появление блоков при прокрутке, счётчики, лайтбокс для фотоальбома,
карточки с подсветкой при наведении. Все анимации отключаются при настройке системы
«уменьшить движение».

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: первый экран, преимущества, цены (вкладки), как это работает, сервис, склоны, видео, отзывы, FAQ, контакты с картой |
| `prices.html` | Полный прайс проката, калькулятор стоимости на несколько дней с кнопкой «Забронировать», распродажа |
| `service.html` | SKI-сервис: описание, прайс по разделам, когда пора в сервис |
| `slopes.html` | Склоны рядом: Сорочаны, парк «Яхрома», Волен, Степаново, видеообзор |
| `contacts.html` | Контакты, статус «открыто сейчас», график, карта, как добраться, форма заявки |

## Скорость

- Шрифты лежат в `fonts/` (без запросов к Google Fonts); для них описаны метрически
  подогнанные системные запасные шрифты (`Unbounded Fallback`, `Manrope Fallback`),
  поэтому текст не «прыгает», когда догружается фирменный шрифт. Латинский
  расширенный набор урезан до знака ₽ (3 КБ вместо 118 КБ).
- Прайс и таблица SKI-сервиса предрендерены в HTML при сборке из `js/data.js`
  (`src/build.py`, нужен `node`); `main.js` потом перерисовывает их теми же данными.
- Все фото локальные, с WebP-версией; внешних запросов на страницах нет, кроме
  погоды (Open-Meteo), которая при недоступности просто не показывается.
- Ориентиры на эмуляции 4G (4 Мбит/с, 100 мс): первая отрисовка ≈0,5 с,
  LCP ≤1 с, сдвиг макета (CLS) ≤0,01 на всех страницах.

## Интро «спуск к прокату» (`intro.html`)

Страница открывает сайт как мини-фильм. Сначала стартовый экран с кнопкой «Поехали»:
нажатие — это жест пользователя, поэтому видео и звук ветра включаются сразу (браузеры
не разрешают звук без клика). Дальше на весь экран идёт видео спуска от первого лица.
По пути пять «станций»: лыжник плавно тормозит, кадр замирает на секунду и темнеет,
сбоку появляется стеклянная карточка раздела (Прокат → Цены → SKI-сервис → Склоны →
Контакты). Клик по карточке ведёт в раздел, клик мимо — едем дальше. После последней станции
лыжник ещё ~3,5 с едет вниз, затем появляется меню сайта.
Настройки станций — `CFG` в начале `js/intro.js` (моменты, длительность паузы, скорость).

- Ролик — `video/descent.mp4` и `video/descent.webm` (11 с, 1280×720): съёмка от первого лица,
  сгенерирована нейросетью по заказу владельца (лыжи и руки с палками в кадре). Предыдущие
  варианты: вид вслед за лыжником (Pexels) — ветка `intro-video-v1`. Чтобы заменить ролик,
  положите свой файл с теми же именами; без файла интро работает на фотографии с таймером.
- Настройки — в начале `js/intro.js`: `pov: true` включает маску горнолыжных очков
  (для съёмки от первого лица), `gatesAt` — моменты появления ворот в долях длительности.
- Без JavaScript или при настройке «уменьшить движение» сразу показывается меню.
- Экспериментальная 3D-версия сохранена как `intro-3d.html` (three.js).
- Рабочая версия сайта без интро зафиксирована в ветке `stable`.

## Как редактировать

Все цены, контакты, график и ссылки на карты лежат в одном файле — **`js/data.js`**.
Поменяйте число там, и оно обновится на всех страницах и в калькуляторе.

- `phone`, `email`, `address` — контакты.
- `whatsapp` / `telegram` — впишите номер/логин, и кнопки появятся сами (пусто = скрыты).
- `hours` — график; `close: 26` означает «до 02:00 следующего дня».
- `rental` — прайс проката, `service` — прайс сервиса.
- `rating` — рейтинг и число оценок на Яндекс Картах.

Стили — `css/style.css`, логика — `js/main.js`. Тексты страниц — в `src/pages/`
(см. «Сборка» ниже). Собранный сайт — статические файлы в корне: открыть `index.html`
в браузере достаточно, серверу ничего не нужно.

## Сборка

HTML в корне генерируется скриптом **`src/build.py`** (нужны `python3` и `node`):

```
python3 src/build.py          # пересобрать index/prices/service/slopes/contacts/intro.html и sw.js
python3 src/build.py --check  # убедиться, что HTML в корне соответствует исходникам
```

Исходники:

| Путь | Что там |
|---|---|
| `src/layout/head.html` | общий `<head>`: мета-теги, шрифты, стили (`{{TITLE}}`, `{{DESCRIPTION}}`, `{{CANONICAL}}`) |
| `src/layout/header.html` | меню и шапка |
| `src/layout/footer.html` | подвал, нижняя панель, подключение скриптов и сервис-воркера |
| `src/layout/schema.html` | разметка schema.org (организация, адрес, график) — на главной и в контактах |
| `src/pages/*.html` | содержимое `<main>` каждой страницы; в начале файла — `title`, `description`, `canonical`, по желанию `schema: yes` и `preload: <картинка первого экрана>` |
| `src/pages/intro.html` | интро целиком (своя разметка), копируется как есть |
| `src/render.mjs` | предрендер прайса и таблицы сервиса из `js/data.js` (разметка та же, что в `main.js`) |

Сборка подставляет штамп `?v=ГГГГММДДЧЧММ` ко всем css/js/шрифтам и в `VERSION` сервис-воркера,
поэтому после каждой правки нужно пересобрать и закоммитить **и исходники, и HTML в корне** —
GitHub Pages публикует репозиторий без сборки. Пустые `<ul data-pricelist="…">` и
`<div data-service>` в исходниках заполняются при сборке; правьте цены только в `js/data.js`.
Workflow `.github/workflows/check.yml` при каждом пуше проверяет, что HTML не разошёлся с исходниками.

## Фото и видео

- Основные фотографии — собственные снимки ZSKI из фотоальбома оригинального сайта,
  оптимизированные до 100–300 КБ (`img/photos/`). Логотип — `img/logo.png`.
- Пейзажи курортов на странице «Склоны» подгружаются с [Pexels](https://www.pexels.com/license/)
  (свободная лицензия). Если фото недоступно, показывается фирменный градиент.
- Видео — «Совет по уходу за лыжами» с оригинального сайта и обзоры курортов с YouTube,
  встраиваются только по клику. ID роликов — в атрибутах `data-video` в HTML.
- Карта — виджет Яндекс Карт по координатам павильона (`address.lat/lng`, `mapEmbed` в `js/data.js`).
- Скриншоты оригинального сайта для сравнения — в `docs/original/`.

## Публикация

**GitHub Pages:** в настройках репозитория Settings → Pages → Source выберите
«GitHub Actions». Workflow `.github/workflows/pages.yml` публикует сайт при каждом пуше
в `main`. Для своего домена добавьте файл `CNAME` с `zski.ru` и настройте DNS.

**Любой хостинг:** просто загрузите содержимое папки на сервер — это статические файлы.

## Скорость

- Шрифты лежат в `fonts/` (без обращений к Google Fonts, которые в России замедлены).
- Фото отдаются в WebP с запасным JPEG (`<picture>`), ленивая загрузка, плавное проявление.
- Карта: лёгкая схема проезда, интерактивный виджет Яндекс Карт грузится только по кнопке.
- Сервис-воркер `sw.js` кэширует статику — повторные переходы мгновенные, страницы открываются
  и без сети. Переходы между страницами анимированы (View Transitions), соседние страницы
  предзагружаются (Speculation Rules).
- Погода и снег в Яхроме на первом экране — Open-Meteo без ключа, кэш на час; обратный отсчёт
  до сезона настраивается в `js/data.js` (`seasonStart`, `seasonEnd`).

## Проверка

Сайт проверен в headless Chromium на ширине 390 px и 1366 px: без ошибок JavaScript,
без горизонтальной прокрутки, калькулятор, вкладки, меню и статус работы функционируют.
