# ZSKI — новый сайт проката лыж и сноубордов

Редизайн сайта [zski.ru](http://zski.ru) — прокат горных лыж и сноубордов, SKI-сервис,
хранение и консервация инвентаря в Яхроме (61-й км Дмитровского шоссе).

Анализ оригинального сайта (сильные и слабые стороны) — в [ANALYSIS.md](ANALYSIS.md).

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: первый экран, преимущества, цены (вкладки), как это работает, сервис, склоны, видео, отзывы, FAQ, контакты с картой |
| `prices.html` | Полный прайс проката, калькулятор стоимости на несколько дней с кнопкой «Забронировать», распродажа |
| `service.html` | SKI-сервис: описание, прайс по разделам, когда пора в сервис |
| `slopes.html` | Склоны рядом: Сорочаны, парк «Яхрома», Волен, Степаново, видеообзор |
| `contacts.html` | Контакты, статус «открыто сейчас», график, карта, как добраться, форма заявки |

## Как редактировать

Все цены, контакты, график и ссылки на карты лежат в одном файле — **`js/data.js`**.
Поменяйте число там, и оно обновится на всех страницах и в калькуляторе.

- `phone`, `email`, `address` — контакты.
- `whatsapp` / `telegram` — впишите номер/логин, и кнопки появятся сами (пусто = скрыты).
- `hours` — график; `close: 26` означает «до 02:00 следующего дня».
- `rental` — прайс проката, `service` — прайс сервиса.
- `rating` — рейтинг и число оценок на Яндекс Картах.

Тексты страниц — прямо в HTML-файлах. Стили — `css/style.css`, логика — `js/main.js`.
Зависимостей и сборки нет: открыть `index.html` в браузере достаточно.

## Фото и видео

- Основные фотографии — собственные снимки ZSKI из фотоальбома оригинального сайта,
  оптимизированные до 100–300 КБ (`img/photos/`). Логотип — `img/logo.png`.
- Пейзажи курортов на странице «Склоны» подгружаются с [Pexels](https://www.pexels.com/license/)
  (свободная лицензия). Если фото недоступно, показывается фирменный градиент.
- Видео — «Совет по уходу за лыжами» с оригинального сайта и обзоры курортов с YouTube,
  встраиваются только по клику. ID роликов — в атрибутах `data-video` в HTML.
- Карта — виджет Яндекс Карт по координатам павильона (`address.lat/lng`, `mapEmbed` в `js/data.js`).
- Скриншоты оригинального сайта для сравнения — в `docs/original/`.

## Публикация

**GitHub Pages:** в настройках репозитория Settings → Pages → Source выберите
«GitHub Actions». Workflow `.github/workflows/pages.yml` публикует сайт при каждом пуше
в `main`. Для своего домена добавьте файл `CNAME` с `zski.ru` и настройте DNS.

**Любой хостинг:** просто загрузите содержимое папки на сервер — это статические файлы.

## Проверка

Сайт проверен в headless Chromium на ширине 390 px и 1366 px: без ошибок JavaScript,
без горизонтальной прокрутки, калькулятор, вкладки, меню и статус работы функционируют.
